🎯 Project Objective
Develop a quantitative model to explain and predict Nvidia option price movements using Greeks via linear modeling, and backtest one or more investment strategies based on those predictions.

📝 Introduction
This project aims to create a robust quantitative model to predict Nvidia option price movements using Greeks. Although the project is complete, the results are not conclusive due to an insufficient number of features for the methods employed. Augmenting the feature set is a crucial next step to improve model performance.

🧱 Project Structure
1 - Data Preparation & Feature Engineering
2 - Option Return Modeling Using Greeks
3 - Backtesting Prediction-Based Trading Strategies
🔍 Augmenting Features for Improved Performance

Augmenting the feature set is an excellent approach to enhance the performance of your model. Here are some ideas for new features that you could add:

1. Technical Indicators
Moving Averages: Simple Moving Average (SMA), Exponential Moving Average (EMA), etc.
RSI (Relative Strength Index): Momentum indicator.
MACD (Moving Average Convergence Divergence): Trend indicator.
Bollinger Bands: Volatility indicator.
Stochastic Oscillator: Momentum indicator.
2. Volume Indicators
Transaction Volume: Daily or average volume over a period.
On-Balance Volume (OBV): Volume-based momentum indicator.
3. Volatility Indicators
ATR (Average True Range): Measure of volatility.
Historical Volatility: Calculated over different periods.
4. Sentiment Indicators
Social Media Sentiment: Analysis of sentiment from tweets or news articles.
Positioning Indicators: Such as the Commitment of Traders (COT) report.
5. Macroeconomic Data
Interest Rates: Central bank policy rates.
Economic Indicators: GDP, unemployment rate, inflation, etc.
Market Indices: S&P 500, VIX (volatility index), etc.
6. Market Data
Commodity Prices: Gold, oil, etc.
Exchange Rates: Major currency pairs.
7. Temporal Features
Day of the Week: Calendar effect.
Month of the Year: Seasonality.
Time of Day: For intraday data.
8. Derived Features
Financial Ratios: P/E ratio, ROE, etc.
Greeks Combinations: For example, the Delta/Gamma ratio.
9. Alternative Data
Satellite Data: To track economic activity.
Credit Card Transaction Data: To track consumption.
